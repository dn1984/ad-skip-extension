Расширение для Яндекс Браузера и других Chromium-браузеров, которое убирает рекламу в видео на **rutube.ru** и **dzen.ru**: рекламные вставки в плеере и наложенные баннеры поверх видео.

Никаких внешних серверов, аккаунтов и телеметрии: расширение работает только с тем, что ваш браузер и так загружает, и ничего не отправляет наружу.

## Возможности

| Сайт | Что убирается | Как |
|---|---|---|
| Rutube | Прероллы, midroll и постролл в плеере | Вырезание рекламной конфигурации из ответа `/api/play/options/` |
| Дзен | Наложенный баннер в углу видео | Скрытие контейнера и нажатие штатной кнопки «Закрыть баннер» |
| Дзен | Рекламный ролик внутри видео (если появится) | Запасной режим: ускорение и выключение звука на время вставки |
| Дзен | Рекламные запросы плеера (по желанию) | Подмена ответа `yandex.ru/ads/meta/*` пустым JSON |

Дополнительно:

- счётчик убранной рекламы на значке расширения и в панели;
- настройки применяются к уже открытым вкладкам без перезагрузки;
- работают встроенные плееры (`rutube.ru/embed/...`) благодаря `all_frames`.

## Установка

Расширение ставится из папки в режиме разработчика.

1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте, либо склонируйте:
   ```sh
   git clone https://github.com/dn1984/ad-skip-extension.git
   ```
2. Откройте `browser://extensions/` (Яндекс Браузер) или `chrome://extensions/` (Chrome).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку репозитория целиком.
5. Закрепите расширение на панели, чтобы видеть счётчик.

Требуется Chromium **111 или новее** — из-за `world: "MAIN"` в `content_scripts`.

После изменения файлов нажмите круглую стрелку ↻ на странице расширений и обновите вкладку сайта.

## Как это работает

### Rutube

Реклама приходит не отдельными запросами, а описанием в ответе `/api/play/options/`: прероллы, midroll и постролл. Плеер сам решает, когда их показать.

1. `src/page-hook.js` выполняется в контексте страницы (`world: "MAIN"`) до загрузки плеера.
2. Перехватывает `fetch` (и `XMLHttpRequest` как резерв).
3. Из ответа `play/options` удаляются поля `advert`, `ad_breaks` и рекламные поля `appearance`.
4. Плеер получает ответ без рекламы и играет видео с начала.

### Дзен

**Наложенный баннер в углу плеера.** Плеер строит его сам:

```html
div.video-viewer--video-viewer-player-ad-banner__banner-XX
  button[aria-label="Закрыть баннер"]
  div#teaser-banner-0[data-testid="video-player-teaser-ad-banner"]
    div#video-player-teaser.video-card-ads
```

`src/dzen-hook.js` находит контейнер, помечает `data-ad-skip-hidden`, скрывает его и нажимает «Закрыть баннер», чтобы плеер убрал разметку сам. Те же селекторы продублированы в `src/hide-ads.css`, поэтому баннер не мигает до первого кадра.

**Рекламный ролик внутри видео.** Запасной режим: `src/dzen-hook.js` ищет надёжные признаки вставки — элементы рекламного SDK (`adfox`, `vast`, `vpaid`, `video-player-ad`), кнопку «Пропустить», либо надпись «Реклама N» на коротком ролике. На время вставки включается ускорение (по умолчанию 16×) и выключается звук, после неё восстанавливаются прежние значения. Сам баннер из этой проверки исключён, поэтому обычное видео не ускоряется.

**Рекламные запросы (по желанию).** Переключатель «Резать рекламные запросы» подменяет ответ `yandex.ru/ads/meta/*` пустым JSON. Это останавливает и баннер, и рекламные карточки в ленте, но рекламный скрипт Дзена пишет ошибки в консоль, поэтому по умолчанию режим выключен.

## Настройки

Хранятся в `chrome.storage.sync` и доступны из панели расширения:

| Настройка | По умолчанию | Описание |
|---|---|---|
| Отключать рекламу | включено | Основной режим для обоих сайтов |
| Скрывать баннеры на видео | включено | Плашка в углу плеера Дзена и наложенные блоки |
| Ускорять рекламу | включено | Запасной режим для вставок, которые всё же дошли до плеера |
| Скорость рекламы | 16× | 8× / 16× / 32× |
| Резать рекламные запросы | выключено | Сетевой режим для Дзена (см. выше) |

## Приватность

Расширение **не собирает и не передаёт** никаких данных: нет аналитики, нет внешних запросов, нет аккаунтов. Подробности — в [PRIVACY.md](PRIVACY.md).

Коротко:

- нет `host_permissions` на сторонние домены, нет удалённого кода;
- настройки лежат в `chrome.storage.sync` — это хранилище браузера, оно может синхронизироваться между вашими устройствами средствами самого браузера;
- расширение не читает пароли, cookies и содержимое страниц за пределами плееров.

## Ограничения

- Расширение меняет только то, что получает плеер в вашем браузере. Серверы Rutube и Дзена, подписка и показы не затрагиваются.
- Если Rutube изменит структуру `/api/play/options/`, нужно обновить `stripAdConfig` в `src/page-hook.js`.
- Селекторы баннера Дзена привязаны к CSS-модулям плеера (`video-viewer--video-player-ad-banner-layout__*`). Хеши в именах классов меняются при обновлениях Дзена — тогда правится `BANNER_CONTAINER_SELECTORS` в `src/dzen-hook.js` и `src/hide-ads.css`.
- Рекламные карточки в ленте и под видео Дзена не скрываются: это не реклама в видео. Частично их убирает только режим «Резать рекламные запросы».
- Рекламная выдача зависит от региона, авторизации и настроек показа. Схема проверена, но гарантии на будущие изменения нет.
- Полноценным блокировщиком расширение не является.

## Разработка и проверка

Внешних зависимостей и сборки нет: это статическое расширение, файлы грузятся как есть.

```sh
# синтаксис всех скриптов
node --check src/page-hook.js
node --check src/dzen-hook.js
node --check src/bridge.js
node --check src/background.js
node --check src/popup.js

# валидность манифеста
node -e "JSON.parse(require('fs').readFileSync('manifest.json','utf8'))"
```

То же самое выполняет CI в `.github/workflows/ci.yml` при каждом push и pull request.

Ручная проверка Rutube: откройте ролик с рекламными вставками, в консоли страницы выполните `__RUTUBE_AD_SKIP__.stats()` — `blockedResponses` должен быть больше нуля.

Ручная проверка Дзена: откройте видео, в консоли выполните `__AD_SKIP_DZEN__.stats()` — `bannerAdsRemoved` увеличивается, когда скрывается баннер.
