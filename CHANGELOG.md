# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-15

### Добавлено

- Поддержка **dzen.ru**: новое разрешение в манифесте, `src/dzen-hook.js` в MAIN-мире.
- Скрытие наложенного баннера в правом нижнем углу плеера Дзена: поиск контейнера по `video-viewer--video-player-ad-banner__*` и `[data-testid="video-player-teaser-ad-banner"]`, нажатие штатной кнопки «Закрыть баннер».
- Запасной режим для рекламных вставок внутри видео Дзена: ускорение и выключение звука по признакам рекламного SDK.
- Необязательный режим «Резать рекламные запросы» для Дзена (подмена `yandex.ru/ads/meta/*`).
- CSS-правила в `src/hide-ads.css`, скрывающие баннер Дзена до первого кадра.
- Счётчик «баннеров скрыто» в панели и на значке расширения.

### Изменено

- Расширение переименовано в **Ad Skip — Rutube и Дзен**.
- Канал обмена сообщениями между страницей и расширением стал общим для двух сайтов (`__adSkip`).
- `src/bridge.js` сам выбирает, какой хук подставлять на текущем сайте.
- Панель управления показывает состояние для обоих сайтов.

### Исправлено

- Баннер Дзена больше не может включить ускорение обычного видео: элементы баннера исключены из проверки рекламной вставки.

## [1.0.0] — 2026-11-14

### Добавлено

- Первая версия: удаление рекламных вставок Rutube из ответа `/api/play/options/`.
- Запасной режим ускорения рекламы с восстановлением скорости и звука.
- Панель управления и счётчик на значке.
- Скрытие известных рекламных контейнеров Rutube.
