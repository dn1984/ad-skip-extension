# Как помочь проекту

Спасибо за интерес! Ниже — как предложить изменение так, чтобы его было легко проверить и принять.

## Сообщить о проблеме

Откройте [Issue](https://github.com/dn1984/ad-skip-extension/issues/new/choose) и выберите шаблон. Для бага полезно приложить:

- сайт и ссылку на видео (или его тип: Rutube / Дзен, обычное видео / эфир / embed);
- версию браузера и версию расширения (видна в панели расширения);
- что ожидалось и что произошло;
- вывод из консоли страницы:
  - Rutube: `__RUTUBE_AD_SKIP__.stats()`
  - Дзен: `__AD_SKIP_DZEN__.stats()`
- при необходимости — скриншот с обведённым рекламным блоком.

Перед отправкой уберите из скриншотов и логов всё личное: имена, почту, идентификаторы аккаунта, ссылки с токенами.

## Предложить улучшение

Создайте Issue с шаблоном «Идея» и опишите задачу, а не только решение: какой сайт, какой тип рекламы, как это должно выглядеть для пользователя.

## Pull request

1. Форкните репозиторий и создайте ветку от `main`:
   ```sh
   git checkout -b fix/dzen-banner-selector
   ```
2. Держите изменение узким: один PR — одна задача.
3. Соблюдайте стиль существующего кода: 4 пробела, `'use strict'`, IIFE, комментарии по-русски, осмысленные имена.
4. Не добавляйте зависимости, сборщики и внешние запросы — расширение остаётся статическим и без сети.
5. Проверьте локально:
   ```sh
   node --check src/page-hook.js
   node --check src/dzen-hook.js
   node --check src/bridge.js
   node --check src/background.js
   node --check src/popup.js
   node -e "JSON.parse(require('fs').readFileSync('manifest.json','utf8'))"
   ```
6. Проверьте поведение руками: загрузите папку как распакованное расширение, откройте страницу нужного сайта, убедитесь, что реклама убрана и обычное видео не ускорено.
7. Опишите в PR: что изменилось, как проверяли, что видно в `stats()`.

## Что не принимается

- Обход платного доступа, авторизации и серверной логики сервисов.
- Сбор данных пользователей, аналитика, телеметрия, внешние запросы.
- Код, требующий новых разрешений без обоснования.
- Массовые переименования и переформатирование «заодно».

## Коммиты

Сообщения — короткие и по делу, в повелительном наклонении:

```
fix(dzen): hide teaser banner by testid
feat(rutube): strip ad_breaks from play options
docs: describe privacy model
```
